# FE brief — #270 MCP server: prikaz porekla rezervacije (M4)

## Šta je novo u BE API-ju

MCP server (`/api/mcp`) i PRM nisu FE površina (koriste ih AI klijenti, npr. Claude). FE-u je bitna jedna promena:
**svaki odgovor sa rezervacijom sada nosi poreklo** (`origin`, `originClient`), za korisnika i za biznis.

### Izmenjeni endpoint-i (isti `ReservationResponse`, dva nova polja)

| Metoda | Putanja | Napomena |
|---|---|---|
| `GET` | `/api/reservations` | lista (`ReservationResponse[]`) |
| `POST` | `/api/resources/{resourceId}/reservations` | kreiranje, telo zahteva nepromenjeno |
| `GET` | `/api/resources/{resourceId}/reservations/{id}` | detalji |
| `POST` | `/api/resources/{resourceId}/reservations/{id}/approve` | odobravanje (biznis) |
| `POST` | `/api/resources/{resourceId}/reservations/{id}/reject` | odbijanje (biznis) |
| `POST` | `/api/resources/{resourceId}/reservations/{id}/cancel` | otkazivanje (korisnik) |
| partnerski | `/api/client-applications/reservations...` | isti DTO, `origin = CLIENT_APPLICATION` |

Zahtevi se ne menjaju.

### TypeScript

```ts
type ReservationOrigin = 'RESERVA_APP' | 'CLIENT_APPLICATION' | 'AI_ASSISTANT';

interface ReservationResponse {
  id: string;
  userId: string | null;
  resourceId: string;
  serviceId: string;
  startTime: string;   // ISO local date-time, lokalno vreme biznisa
  endTime: string;
  status: string;      // PENDING_APPROVAL | CONFIRMED | REJECTED | CANCELLED | ...
  origin: ReservationOrigin;      // NOVO, uvek prisutno
  originClient: string | null;    // NOVO; npr. "Claude", samo kad je origin === 'AI_ASSISTANT'
  service: { id: string; name: string; minDuration: number; maxDuration: number; durationUnit: string; durationStep: number } | null;
  resource: { id: string; name: string; type: string } | null;
  business: { id: string; name: string } | null;
}
```

### Greške

Postojeće (`{ message, code? }`). Rezervacije iz MCP-a koriste iste kodove (`RESERVATION_SLOT_TAKEN`, 422 za rate limit
`error.reservation.rate_limit_exceeded` samo preko MCP-a, ne preko REST-a).

## Šta FE treba da uradi (M4)

- Dashboard/detalji rezervacije biznisa (owner/employee) i korisnikova lista/detalji: prikaži oznaku porekla.
  - `AI_ASSISTANT` → "Rezervisano preko AI asistenta (`originClient`)", npr. "Claude"; ako je `originClient` null, samo "AI asistent".
  - `CLIENT_APPLICATION` → "Partner"; `RESERVA_APP` → bez oznake (podrazumevano).
- Tretiraj nepoznatu vrednost `origin` kao `RESERVA_APP` (enum može da raste).
- `originClient` je tekst koji dolazi spolja (ime MCP klijenta): renderuj kao običan tekst, nikad kao HTML.
- Regeneriši API tipove iz OpenAPI-ja ako ih FE generiše.
